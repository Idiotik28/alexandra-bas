# Александра Бас — лендинг мастера по наращиванию волос

Скелет одностраничника по референсу **Minerva**: композиция, сетка и порядок
секций повторены, палитра пересобрана под главное фото (пудрово-розовая стена
+ тёплый блонд). Фотографий в вёрстке нет — везде стоят заглушки-слоты.

Стек: чистый HTML/CSS/JS + GSAP (ScrollTrigger). Сборка не нужна.

## Запуск

```bash
python3 -m http.server 8777    # или: npx serve .
```

Открыть `http://localhost:8777`. Через `file://` не заработают локальные шрифты.

### Кэш

`index.html` отдаётся с `no-cache`, а стили и скрипты подключены с суффиксом
`?v=2`. Это нужно, чтобы браузер не склеивал новый HTML со старыми
`style.css` / `main.js` — такая смесь выглядит как полностью сломанная вёрстка.

**После правок в CSS или JS меняйте номер версии** во всех ссылках
(`?v=2` → `?v=3`) в `index.html` и `privacy.html`. Перед выкладкой в продакшн
версии лучше оставить — так же обновляется кэш у клиентов.

## Структура

```
index.html                  # лендинг, 8 секций
privacy.html                # политика конфиденциальности (черновик под 152-ФЗ)
assets/
  css/style.css             # все токены в :root
  css/fonts.css             # @font-face, сгенерирован скриптом
  js/main.js                # заглушки фото, меню, календарь и слоты, формы, моушен
  js/vendor/                # gsap.min.js + ScrollTrigger.min.js локально
  fonts/                    # Onest + Cormorant, woff2, кириллица
  img/                      # логотип + сюда кладутся фото
docs/screenshots/           # прогон на 1440 / 375
```

## Шапка

Логотип в левом углу, навигация по центру, кнопка «Записаться» и бургер справа.
Ниже 900px навигация прячется в бургер-меню. Меню открывается и закрывается
плавно (GSAP: затемнение + поочерёдное появление пунктов); без GSAP
или при `prefers-reduced-motion` просто показывается без анимации.

## Секции

1. **Герой** — фото на всю ширину **без блюра и затемнения**, заголовок
   с италик-акцентом, CTA, две стеклянные мини-карточки и карточка-ссылка
   «Мои работы» → ведёт в галерею.
2. **Услуги** — заголовок слева, три карточки разной высоты справа.
3. **Обо мне** — портрет и короткий рассказ, четыре факта строками.
4. **Работы** — ровная сетка 3×2.
5. **Полоса с размытым фото** — фон блюрится, поверх стеклянная карточка с цитатой.
6. **Запись** — календарь, слоты времени и карточка подтверждения.
7. **Уход** — четыре карточки товаров с кнопкой корзины.
8. **Почему ко мне** — акцентная плашка, четыре преимущества, счётчики 900+ / 8.

Плюс тёмный футер: живая Яндекс.Карта, контакты, логотип, подписка.

### Про герой

Главное фото показывается как есть — никакого блюра. Текст в герое **тёмный**,
логотип в шапке — `logo-dark.png`: на светлой розовой стене белый вариант
не читался. Слева лежит `.hero__scrim` — светлая подложка под текст на случай,
если кадр обрежется на волосах. Фото она не трогает; чтобы убрать совсем,
достаточно удалить `<div class="hero__scrim">` из разметки.

Кадрирование героя задаётся в `.hero__bg`: `background-size: auto 118%` +
`background-position: 16% 20%` — лёгкий зум уводит модель вправо,
освобождая левую часть под текст.

### Про запись

Пошаговый мастер: **Дата → Время → Запись**. Шаг переключается сам после
выбора, назад — одной кнопкой внизу. Высота карточки анимируется, чтобы
блок не прыгал; при `prefers-reduced-motion` переключение мгновенное.

1. **Дата** — минималистичный календарь, воскресенья и прошедшие дни
   заблокированы. Внизу кнопка «Пока не готова — нужна консультация»:
   она пропускает выбор даты и времени и сразу ведёт на третий шаг
   с другим текстом сообщения.
2. **Время** — будни `10:00 / 12:30 / 15:00 / 17:30`, суббота
   `11:00 / 13:30 / 16:00`. Слотов немного, потому что процедура долгая;
   список правится в начале `main.js` (`SLOTS_WEEKDAY`, `SLOTS_SATURDAY`).
3. **Запись** — сверху предпросмотр сообщения, под ним кнопки
   Telegram, WhatsApp, Позвонить.

**Подстановка текста.** WhatsApp принимает готовое сообщение прямо
в ссылке (`wa.me/...?text=`) — там всё автоматически. У Telegram такого
параметра нет: прямая ссылка на чат не умеет открываться с заполненным
полем ввода. Поэтому по клику на Telegram текст молча копируется в буфер,
и подсказка под сообщением меняется на «Текст скопирован — вставьте его
в чат». Для звонка текст не нужен.

Формы заявки на сайте нет — связь только напрямую через мессенджер
или звонок.

Контакты мастера задаются в одном месте — объект `CONTACTS`
в начале `main.js`: телефон `79775891893` (он же для WhatsApp)
и ссылка на Telegram.

### Про карту

В футере встроен виджет Яндекс.Карт (`yandex.ru/map-widget/v1`), API-ключ
не нужен. Сейчас точка ищется по текстовому адресу «Королёв, проезд
Макаренко, 1». Это работает, но **точку стоит сверить** на
`yandex.ru/map-constructor` и заменить `?text=` на точные координаты
`?ll=…&pt=…` — так метка встанет ровно на вход, а не на здание целиком.

Виджет подтягивает сторонние рекламные пиксели Яндекса — это нормально
для их карты, но стоит упомянуть в политике конфиденциальности.
Карта грузится лениво (`loading="lazy"`).

## Куда класть фотографии

Заглушки сами подхватят картинку, как только файл появится по своему пути —
`main.js` проверяет загрузку и подставляет фон, градиент с подписью исчезает.
Менять разметку не нужно.

| Файл | Где | Рекомендуемый размер |
|---|---|---|
| `assets/img/hero-main.jpg` | главный экран | **уже стоит**, 2400×1600 |
| `assets/img/svc-1…3.jpg` | карточки услуг | 900×1150 |
| `assets/img/about-portrait.jpg` | портрет в «Обо мне» | 900×1150, лицо в кадре |
| `assets/img/work-1…6.jpg` | галерея «Работы» | 800×1000 |
| `assets/img/band-1.jpg` | фон полосы с цитатой | 2000×1200 (уйдёт в блюр) |
| `assets/img/booking.jpg` | блок «Запись» | 900×1150, вертикаль |
| `assets/img/prod-1…4.png` | товары | PNG без фона, ~800×900 |
| `assets/img/og.jpg` | превью для мессенджеров | 1200×630 |

`work-1…3.jpg` показываются дважды: в галерее и кружками
на кнопке «Мои работы» в герое.

Логотип уже на месте: `logo-dark.png` (тёмный — в шапке поверх светлого фото),
`logo-light.png` (светлый — в тёмном футере). Пропорции нигде не меняются,
задана только высота, ширина считается автоматически.

Перед сдачей сжать фото: WebP/AVIF, ширина не больше 1600px.

## Дизайн-токены

Всё в `:root` в начале `style.css`, цвета выведены из главного фото.

| Токен | Значение | Роль |
|---|---|---|
| `--cream` | `#FBF6F3` | основной фон |
| `--cream-2` | `#F4EAE5` | карточки |
| `--blush` | `#E9CBD6` | пудровый розовый со стены на фото |
| `--sand` | `#D6BCA9` | тёплый песок, оттенок блонда |
| `--accent` | `#A55A72` | кнопки и секция «Почему ко мне» (4.9:1 к белому) |
| `--accent-dk` | `#8E4F63` | ссылки на светлом фоне, ховеры |
| `--ink` | `#1F1A1C` | текст, форма, футер |
| `--muted` | `#6E5C61` | вторичный текст (5.2:1 к фону) |

Шрифты: **Onest** (текст и заголовки) + **Cormorant** (италик-акценты и цитата).
Оба с кириллицей, лежат локально. Перегенерировать набор — скриптом из
`scripts/getfonts.py`.

Моушен: один набор на весь сайт — `power2.out`, 0.5–0.8 с, появление
однократное (при скролле вверх контент не исчезает), `prefers-reduced-motion`
отключает всё.
